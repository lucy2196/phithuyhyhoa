# Hy Hòa – Vòng ngọc phỉ thúy

Web giới thiệu thương hiệu Hy Hòa. Trang tĩnh (HTML, CSS, JS), chạy trên GitHub Pages.

## Cấu trúc

- `index.html` – trang chủ
- `assets/css/style.css` – giao diện (máy tính và điện thoại)
- `assets/js/main.js` – menu, menu con, thanh đầu trang khi cuộn
- `assets/img/` – logo, ảnh cửa hàng

## Nội dung cần điền

Các chỗ trong ngoặc vuông `[...]` trong `index.html` chờ thông tin thật: câu định vị, đơn vị kiểm định, địa chỉ, số Zalo, Facebook, giờ mở cửa, tên hộ kinh doanh, mã số thuế, ảnh và video từng chiếc vòng.
